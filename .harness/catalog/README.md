# Catálogo: consultar somente após identificar uma lacuna

O fluxo padrão é contexto → mudança OpenSpec → implementação → verificação → arquivo. Boilerplates é uma base condicional para projetos novos. Os demais recursos são selecionados, não acumulados.

Veja o [filtro de redundância](../docs/curadoria.md) antes de adicionar outro kit. Abra uma ficha e só então o arquivo necessário. O [índice de skills upstream](skills-upstream.md) é para busca pontual, não leitura integral.
