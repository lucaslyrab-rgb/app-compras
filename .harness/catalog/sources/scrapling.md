## O que oferece

Framework Python de parsing, requisições HTTP, navegação dinâmica e crawling. Inclui CLI, integração MCP e skill oficial com referências da API.

## Quando consultar

Considerar para extração de dados web e coleta repetível. Escolher HTTP simples quando suficiente e navegador quando a página exigir renderização.

## Cuidados de integração

A instalação básica cobre o parser; fetchers, browser, CLI e MCP possuem extras. A skill menciona --ai-targeted para extração voltada a IAs; sanitização não torna conteúdo externo confiável. Respeitar o escopo de coleta e os limites da fonte.
