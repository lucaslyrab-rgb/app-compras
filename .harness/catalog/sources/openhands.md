## O que oferece

No commit consultado, este repositório apresenta Agent Canvas: interface e coordenação de backends para agentes de programação. SDK/Agent Server, cliente TypeScript e automações têm repositórios próprios.

## Quando consultar

Avaliar quando for necessário hospedar uma interface de trabalho e conectar agentes em ambientes locais, remotos ou isolados.

## Cuidados de integração

Não usar instruções de versões antigas como se descrevessem esta árvore. O modo sem sandbox dá acesso à máquina; deployments precisam considerar autenticação, montagem de diretórios e rede. Não foi executado nesta curadoria.
