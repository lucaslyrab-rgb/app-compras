## O que oferece

Runtime e interfaces para trabalhar com modelos, com CLI, API REST e bibliotecas de integração. A documentação de API é mantida também no site oficial.

## Quando consultar

Avaliar quando execução de modelos e integração com aplicações fizerem parte da arquitetura. Medir latência, memória e qualidade com a carga real.

## Cuidados de integração

Verificar requisitos de hardware, tamanho de contexto e licença de cada modelo. Não inferir que toda integração mantém dados exclusivamente locais; identificar o backend configurado. Proteger instâncias expostas.
