## O que oferece

Kit com skills, papéis de agentes, workflows, memória, regras e integração de execução voltada ao Antigravity. O manifesto e o grafo de dependências ajudam a escolher módulos sem perder suas referências.

## Quando consultar

Consultar para arquitetura, APIs, bancos, frontend, depuração, testes e revisão. Buscar a skill específica no índice antes de carregar o kit inteiro.

## Cuidados de integração

O README declara Antigravity como runtime de produção; outros consumidores Markdown não têm a mesma garantia. Hooks, sincronização MCP e orquestração exigem integração própria. A importação não os ativa.
