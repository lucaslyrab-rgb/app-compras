# Assets e Referências Visuais

Este diretório armazena referências e ativos aprovados para reutilização corporativa.

Estrutura sugerida:

- `logos/` — marcas e variações oficiais
- `icons/` — ícones próprios ou aprovados
- `screenshots/` — telas de referência visual aprovadas
- `patterns/` — fundos, texturas e grafismos
- `palettes/` — paletas documentadas

## Regra

Não versionar fontes proprietárias/licenciadas sem autorização.

Para cada arte aprovada, registrar quando possível:

- nome;
- finalidade;
- projeto de origem;
- proporção/dimensões;
- paleta;
- observações de uso.
