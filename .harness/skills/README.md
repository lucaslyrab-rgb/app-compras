# Skills: carregamento por objetivo

Leia somente a linha pertinente; não carregue todas as skills na inicialização.

| Objetivo | Entrada | Frequência |
| --- | --- | --- |
| Novo projeto ou realinhamento | [iniciar-projeto](iniciar-projeto/SKILL.md) | Início ou mudança de direção |
| Engenharia e interface do escopo atual | [aplicar-padroes](aplicar-padroes/SKILL.md) | Quando necessário |
| Escolher ferramenta ou integração | [selecionar-recursos](selecionar-recursos/SKILL.md) | Lacuna concreta |
| Explorar ideia | [brainstorm](brainstorm/SKILL.md) | Alternativa a opsx:explore |
| Requisitos globais de produto | [escrever-prd](escrever-prd/SKILL.md) | Produto amplo, sem duplicar specs |
| Arquitetura global / ADR | [escrever-trd](escrever-trd/SKILL.md) | Decisão transversal |
| Criar ou atualizar skill | [skill-creator](skill-creator/SKILL.md) | Manutenção de skills |

As três skills de Fabrício e Skill Creator são originais preservados; as outras três são roteadores locais. OpenSpec é o workflow principal externo, instalado seletivamente no projeto, conforme o [manual](../docs/manual.md). Seus [originais](../upstream/openspec/skills/) ficam como referência; não copie todos para ativação global.

Os kits AG Kit, ECC e afonsoft ficam no [catálogo](../catalog/README.md), fora da seleção padrão. Veja [compatibilidade](../docs/compatibilidade.md) e o [filtro de redundância](../docs/curadoria.md).
